# 📚 "LitMind: Automated Literary Analysis using NLP and Network Visualization"

LitMind is an AI-powered Novel Analyzer that uses Natural Language Processing (NLP) and Generative AI to analyze literary texts and provide meaningful insights.

## 🚀 Project Goals

* Extract text from PDF novels
* Detect characters using Named Entity Recognition (NER)
* Visualize character relationships
* Perform chapter-wise sentiment analysis
* Generate AI-powered summaries
* Build an interactive Streamlit dashboard

## 🛠️ Tech Stack

* Python
* PyMuPDF
* spaCy
* NLTK
* NetworkX
* Plotly
* Streamlit
* Google Gemini API
